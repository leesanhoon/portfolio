# Orchestration Memory

Muc dich: luu quy uoc dieu phoi agent de sau khi compact van tiep tuc lam viec nhat quan.

## Stable rules
- Main agent mac dinh orchestration-first cho task non-trivial.
- Main agent chi nhan report ngan, khong dan lai toan bo phan tich.
- Code changes chi bat dau sau khi da co evidence mapping.
- Uu tien sub-agents: code_mapper -> backend/database/security -> test/docs.

## Reusable handoff template
- Objective
- Scope
- Constraints
- Files to inspect
- Expected output

## Reusable report template
- Findings
- Risks
- Recommendation
- File references

# Task Routing Template

## When a new task arrives
1. Classify task:
   - trivial
   - backend
   - backend + db
   - backend + upload/security
   - multi-area
2. Select agents.
3. Request short reports only.
4. Summarize facts.
5. Make smallest defensible patch.
6. Validate.
7. Persist reusable learning to orchestration memory.

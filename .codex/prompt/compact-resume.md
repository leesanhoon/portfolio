# Compact Resume

Muc dich: moi lan compact hoac quay lai thread, chi can paste 1 lenh ngan de Codex tiep tuc dung bo orchestration cua repo.

## Resume one-liner

```text
Resume task theo orchestration mac dinh cua repo: doc `AGENTS.md`, doc `.codex/prompt/init.md`, `.codex/memory/project-context.md`, `.codex/memory/orchestration-memory.md`, nap lai context can thiet, tiep tuc tu plan dang do hoac tao plan moi neu can, dung sub-agents phu hop, implement patch nho nhat, validate dung muc, va cap nhat memory neu hoc duoc pattern moi.
```

## Resume one-liner with task

```text
Resume task theo orchestration mac dinh cua repo: doc `AGENTS.md`, `.codex/prompt/init.md`, `.codex/memory/project-context.md`, `.codex/memory/orchestration-memory.md`, sau do tiep tuc task nay voi day du flow map -> plan -> sub-agents -> summary -> implement -> validate -> update memory. Task: [mo ta task]
```

## Resume one-liner, planning only

```text
Resume task nhung chua implement. Doc `AGENTS.md`, `.codex/prompt/init.md`, `.codex/memory/project-context.md`, `.codex/memory/orchestration-memory.md`, map lai context can thiet, lap plan, chia sub-task cho agents phu hop, va chi tra ve summary ngan gom files, patterns, plan, risks, validation.
```

## Resume one-liner, implement directly from approved plan

```text
Resume task theo orchestration cua repo va implement theo plan da thong nhat: doc `AGENTS.md`, `.codex/prompt/init.md`, `.codex/memory/project-context.md`, `.codex/memory/orchestration-memory.md`, nhac lai file se doi, sua patch nho nhat, validate dung muc, roi cap nhat memory neu co pattern moi.
```

## Fastest version

```text
Resume theo orchestration cua repo va tiep tuc task dang do.
```

## Suggested usage note

- Neu thread vua compact va ban muon an toan, dung `Resume one-liner with task`.
- Neu task da plan xong tu truoc, dung `Resume one-liner, implement directly from approved plan`.
- Neu chi muon Codex nap lai bo nho lam viec, dung `Fastest version`.
